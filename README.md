# Sprunk

Landing page for Sprunk lemon-lime soda: a 3D can (Three.js), scroll animations (GSAP + ScrollTrigger) and smooth scrolling (Lenis). The interface is built from [Astryx](https://github.com/meta/astryx), Meta's open-source design system (MIT), rendered with React 19 from jsDelivr; Astryx's stylesheets are inlined with their license notice. It's one static `index.html` with no build step.

Open `index.html` in a browser, or serve the folder with any static host.

Note: the nutrition facts, ingredients and production figures are placeholders.
