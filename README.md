# Sprunk

Landing page for Sprunk lemon-lime soda: a 3D can (Three.js), scroll animations (GSAP + ScrollTrigger) and smooth scrolling (Lenis). It's one static `index.html` with no build step.

Open `index.html` in a browser, or serve the folder with any static host.

Note: the nutrition facts, ingredients and production figures are placeholders.
